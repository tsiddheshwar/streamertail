What is Streamertail?

Streamertail is a lightweight CSS utility library that works alongside any existing project. It provides semantic classes that make building UIs intuitive without fighting the cascade.

  • Zero side effects — wrapped in @layer streamertail.base
  • Framework-agnostic — works anywhere CSS works
  • Dual-class system — .st-btn or just .btn
The best library is the one you forget is there.

All styles are opt-in via class names. Nothing changes unless you add a Streamertail class.
